Descrição detalhada

Exceção lançada quando a entrada do usuário termina (EOF, Ctrl+D ou arquivo redirecionado acabou).

Sem ela, InterfaceJogo::solicitarEscolha ficava em loop infinito pedindo uma opção que nunca chegaria. Combate não engole esta exceção: ela sobe até a main, que encerra o jogo de forma limpa.
