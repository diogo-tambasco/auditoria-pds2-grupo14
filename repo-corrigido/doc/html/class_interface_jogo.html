Descrição detalhada

Classe puramente estática responsável pela entrada e saída de dados no console.

  • Esta classe centraliza a formatação de textos, exibição de menus e leitura de escolhas, garantindo que a lógica do jogo (backend) não dependa diretamente de comandos de I/O.
