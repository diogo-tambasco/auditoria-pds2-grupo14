Descrição detalhada

Cidadão comum que frequenta os fundos do bar em busca de uma válvula de escape.

Inimigo introdutório do Clube de Luta. Usa apenas dano físico bruto (socos e chutes), tem baixa defesa física e nenhuma resistência mágica. Serve para o jogador aprender a gerenciar HP e testar ataques básicos.

Invariante
_nivel >= 1
_hp >= 0 && _hp <= _hpMax
